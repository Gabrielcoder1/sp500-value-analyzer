# S&P 500 Value Analyzer

## Project Overview

This project analyzes what an investor is actually buying when buying the S&P 500.

It looks at company count, company age, estimated company weights, sector exposure, sub-industry exposure, and valuation compared to estimated book value.

## Main Question

When someone buys the S&P 500, what are they actually buying?

## Tools Used

- Python
- pandas
- yfinance
- matplotlib
- Jupyter Notebook
- Git and GitHub

## Data Sources

- S&P 500 company list from Wikipedia
- Financial data from yfinance / Yahoo Finance

## Main Findings

- The S&P 500 is diversified across many companies, but it is not equally weighted.
- The top 10 companies made up a large part of the estimated index weight.
- Information Technology was the largest sector by estimated weight.
- Sector exposure looked different when measured by company count versus market-cap weight.
- The estimated aggregate price-to-book ratio showed that the market values the S&P 500 companies much higher than their combined estimated book value.
- Financials had one of the lower aggregate price-to-book ratios.
- The largest sub-industry was not necessarily inside the largest sector, showing that broad sector labels can hide important details.

## Important Note

The weights in this project are estimates. The official S&P 500 uses float-adjusted market capitalization, while this project uses regular market capitalization from yfinance.

## Project Files

- `data/cleaned/sp500_combined_financials.csv` — exported combined dataset
- `reports/sp500_value_analyzer_report.docx` — simplified visual report
- `data/cleaned/charts` — Charts generated by the code

## Limitations

- Estimated weights use regular market capitalization, not official S&P 500 weights.
- yfinance data may have missing, delayed, or unusual values.
- Price-to-book and book value estimates can be affected by accounting rules, intangible assets, share repurchases, and negative book equity.
- This analysis represents one point in time.
